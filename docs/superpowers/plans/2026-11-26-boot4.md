# Spring Boot 4.1.3 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. 用户已批准直接实施到发布，不再设置确认环节。

**Goal:** 发布经过 Spring Boot 4.1.3 回归验证的公开 Fork 与 GitHub Release。

**Architecture:** 保留现有 API，改用 Boot 4 BOM 与 Web MVC starter。用应用的 MVC 消息转换器支持 Jackson 3，保留异常放行和配置语义。

**Tech Stack:** Java 17 基线（本地 JDK 21）、Maven、Spring Boot 4.1.3、Spring MVC 7、Jackson 3、JUnit。

**Spec:** docs/superpowers/specs/2026-11-26-boot4-design.md

## Global Constraints

- Maven 坐标 com.github.wangyongchuannb:graceful-response:6.0.0-boot4。
- 公开 Fork wangyongchuannb/graceful-response，boot4 默认分支，保留 MIT 和上游历史。
- 不发布 Maven Central，不宣称未测试的第三方框架或业务项目兼容性。

## Review Focus

- 自定义 ObjectMapper 对异常放行响应也应生效。
- ResponseEntity 的状态与响应头应保留。
- 非 JSON 内容不能被错误封装。
- 校验异常应返回配置的业务错误码。
- 空返回与已封装响应不能遗漏或重复封装。
